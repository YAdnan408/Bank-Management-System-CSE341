# Bank Management System (Assembly - Emu8086)

A comprehensive Bank Management System implemented in 8086 Assembly language using the Emu8086 emulator. This project simulates core banking operations with a user-friendly command-line interface.

## 🚀 Features

- **Secure Login:** Authenticate using pre-registered account numbers and PINs.
- **Balance Inquiry:** Check your current account balance at any time.
- **Deposit:** Add funds to your account securely.
- **Withdrawal:** Withdraw money with real-time balance validation to prevent overdrafts.
- **Loan Management:**
  - Request loans based on specific criteria.
  - Automatic calculation of interest and total repayment amounts.
- **Interest Calculation:** Earn interest based on your account balance (tiered interest rates).
- **Transaction History:** View your recent deposit and withdrawal activities.

## 🛠️ Requirements

- **Emu8086 Emulator:** The project is designed to run on the Emu8086 microprocessor emulator.

## 📖 How to Run

1.  **Download/Clone** this repository to your local machine.
2.  Install and open the **Emu8086** emulator.
3.  Open the file `341 project updated.txt` in the emulator.
4.  Click on the **Emulate** button.
5.  In the emulation window, click **Run** to start the application.

## 🖥️ Usage

1.  **Login:** Enter your 3-digit account number and 3-digit PIN.
    *   Default Accounts: `123`, `456`, `789`
    *   Default PINs: `111`, `222`, `333`
2.  **Main Menu:** Choose from the following options:
    - `1` - View Balance
    - `2` - Deposit
    - `3` - Withdraw
    - `4` - Loan
    - `5` - Interest
    - `6` - Transaction History
    - `7` - Exit
